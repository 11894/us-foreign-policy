# US foreign policy: sources, timeline and further reading

A single-page site (index.html, no build step, no dependencies).

## Deploy on GitHub Pages
1. On github.com choose New repository, name it `us-foreign-policy`, set it to Public, and create it.
2. Click "uploading an existing file", drag in `index.html` and `.nojekyll`, and commit.
3. Open Settings > Pages, set Source to "Deploy from a branch", choose `main` and `/ (root)`, and save.
4. After a minute or two the site is live at `https://YOUR-USERNAME.github.io/us-foreign-policy/`.

## Deploy on Vercel
1. Put the files in a GitHub repository as above.
2. On vercel.com choose Add New > Project, import the repository, set Framework Preset to "Other", and deploy.
3. The site is live at a `.vercel.app` address.
